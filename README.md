# Automação de Relatórios de Vendas em Excel

Script Python que gera relatórios de vendas formatados automaticamente no Excel.

## O que faz:
- Cria planilhas Excel formatadas automaticamente
- Cabeçalho colorido e estilizado
- Calcula o total de vendas automaticamente
- Ajusta largura das colunas sozinho
- Ideal para lojas e empresas que precisam de relatórios rápidos

## Tecnologias:
- Python
- openpyxl

## Como usar:
1. Instale as dependências: `pip install openpyxl`
2. Edite a lista de vendas no arquivo `organizar_planilha.py`
3. Execute: `python organizar_planilha.py`
4. Abra o arquivo `relatorio_vendas.xlsx` gerado
